# Agent Guidelines

## File and Directory Rules

- **Project Root:** The root of the project is `ai_rss_filter`.
- **Working Directory:** All code changes, additions, and deletions must occur within the `ai_rss_filter/` subdirectory.
- **No Root Level Code:** Do not add, modify, or delete files or directories outside of the `ai_rss_filter/` subdirectory unless explicitly told to do so.

## Coding Style

- All code comments must be written in English.
